## 🎯 Giới thiệu Dự án

Mô tả chi tiết về dự án:
- **Vấn đề cần giải quyết**: Tại sao bạn xây dựng dự án này?
- **Đối tượng sử dụng**: Ai là người dùng chính?
- **Quy mô**: Dự án cá nhân, đồ án tốt nghiệp hay sản phẩm thực tế?

---

## ✨ Tính năng nổi bật

1. **Xác thực người dùng**: Đăng nhập, đăng ký qua JWT / OAuth (Google, GitHub).
2. **Dashboard quản trị**: Báo cáo thống kê, biểu đồ doanh thu theo thời gian thực.
3. **Hiệu năng cao**: Tối ưu tốc độ tải trang, caching dữ liệu với Redis.
4. **Giao diện Responsive**: Hoạt động mượt mà trên cả Mobile, Tablet và Desktop.

---

## 🛠️ Kiến trúc & Công nghệ sử dụng

- **Frontend**: React, Next.js, TailwindCSS, Redux Toolkit
- **Backend**: Node.js, Express, Prisma ORM
- **Cơ sở dữ liệu**: PostgreSQL, Redis
- **DevOps / Hosting**: Docker, AWS EC2, GitHub Actions CI/CD

## 🚀 Hướng dẫn cài đặt và chạy thử local

```bash
# 1. Clone dự án về máy
git clone https://github.com/your-username/ten-repo.git

# 2. Cài đặt các gói phụ thuộc
cd ten-repo
npm install

# 3. Chạy môi trường phát triển
npm run dev
```
